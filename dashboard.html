How it works

        

          Every user you create from the panel as a user/pass or license key logs in the same way —
          your software verifies it with the server. Time expiry, HWID reset, ban — all control is yours,
          from a live SQLite database.
        

        
1
Copy the API Key and the app App ID from the API Keys page.

        
2
Create a user + password or a license key from the Users page.

        
3
Paste the code below into your software — login is ready.

      


      

        
 ISHU AUTH Package — C# ready

        

          Download the package → drop IshuAuth.cs into your project → done.
          No NuGet or package installation is required — .NET's built-in System.Net.Http is enough.
          It is also safe for native AOT builds.
        

        
1
Download Package — it contains IshuAuth.cs + Example.cs + README.txt.

        
2
Drop IshuAuth.cs into your project's source folder.

        
3
Call auth.Verify(user, pass, hwid) in your app — create user, HWID reset, renew and ban are all controlled from the same file.

      


      

        
 Discord Bot — Auto Key Generator

        

          Download the bot source → put your own bot token + ISHU AUTH values → your own Discord bot generates keys.
          Your bot, your name, your icon — users complete a shortener link and receive a 48-hour key automatically.
        

        
1
Download Bot Source — contains bot.py + config.example.json + INSTALL-BOT-GUIDE.txt.

        
2
Create a bot at Discord Developer Portal — set name + avatar there (it becomes YOUR bot).

        
3
Copy config.example.json → config.json → fill bot token, your Discord ID, ISHU AUTH values + shortener link.

        
4
pip install -r requirements.txt then python bot.py — bot is live.
