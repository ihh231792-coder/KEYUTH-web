ISHU AUTH Package — C# ready

Download the package → drop IshuAuth.cs into your project → done. No NuGet or package installation is required — .NET's built-in System.Net.Http is enough. It is also safe for native AOT builds.

1

Download Package — it contains IshuAuth.cs + Example.cs + README.txt.

2

Drop IshuAuth.cs into your project's source folder.

3

Call auth.Verify(user, pass, hwid) in your app — create user, HWID reset, renew and ban are all controlled from the same file.
