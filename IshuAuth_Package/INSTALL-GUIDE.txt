--------------------------------------------------------
WHAT YOU NEED BEFORE YOU START
--------------------------------------------------------
Aapko apne app/project ke liye sirf 4 values chahiye,
jo aapko aapke ISHU AUTH panel se milti hain:

  1) APP ID     (jaise: APP-1LHEK3)
  2) OWNER ID   (jaise: IHH231792GMAILCOM-OFPDR)
  3) SECRET ID  (jaise: SEC_fV0a-...)
  4) VERSION    (jaise: 1.0)

Ye values panel ke:
  -> Installation page (right side "Your values" box) me
  -> Apps page (app card ke andar, copy buttons ke saath)
  dono jagah milti hain.

--------------------------------------------------------
STEP 1 - PACKAGE DOWNLOAD
--------------------------------------------------------
Panel se "Download Package" button dabao
ya ye file download karo:
  https://keyuth-web.onrender.com/IshuAuth_Package.zip

Zip me ye files milengi:
  IshuAuth.cs          -> simple SDK (Verify/Create/Reset/Renew/Ban)
  ISHU_Auth_API.cs     -> name/ownerid/secret/version style SDK
  Example.cs           -> working example
  README.txt           -> SDK details
  INSTALL-GUIDE.txt    -> ye file
  examples/ConsoleDemo -> ya ConsoleDemo (dll/exe) bhi dekh sakte ho

--------------------------------------------------------
STEP 2 - ADD TO YOUR PROJECT (C# / WinForms / Console)
--------------------------------------------------------
1. Zip extract karo
2. IshuAuth.cs (ya ISHU_Auth_API.cs) ko apne project ke
   source folder me copy karo (jaise apne .csproj/.sln ke paas)
3. Visual Studio me project khula hai to us folder ko add karo
   (ya bas file ko project-folder me daal do - build karne pe
   automatically mil jayegi)

--------------------------------------------------------
STEP 3 - LOGIN CODE (4 lines)
--------------------------------------------------------
using ISHU_Auth;

public static api IshuAuthApp = new api(
    name:    "APP-1LHEK3",                    <-- apna APP ID
    ownerid: "IHH231792GMAILCOM-OFPDR",       <-- apna OWNER ID
    secret:  "SEC_fV0a-...",                  <-- apna SECRET ID
    version: "1.0"                            <-- apna VERSION
);

// login:
var res = await IshuAuthApp.login("user123", "pass123");
if (res.success) Console.WriteLine("LOGIN OK @ " + res.expiry);
else Console.WriteLine("DENIED: " + res.message);

// license key login:
var lic = await IshuAuthApp.license("LIC_XXXX-....");
if (lic.success) Console.WriteLine("LOGIN OK @ " + lic.expiry);

--------------------------------------------------------
STEP 4 - ADMIN CONTROL (from your own app)
--------------------------------------------------------
await IshuAuthApp.Create("user2", "pass2", "30d", "user");  // new user
await IshuAuthApp.CreateKey("30d");                          // new license key
await IshuAuthApp.Delete(id);                                // delete user/key
await IshuAuthApp.Ban(id, true);                             // ban
await IshuAuthApp.Ban(id, false);                            // unban
await IshuAuthApp.Renew(id, "7d");                           // renew
await IshuAuthApp.ResetHwid(id);                             // hwid reset

(Sab kuch panel ke Users page se bhi ho sakta hai.)

FAIL HO RAHA HAI? FAILURE TABLE
--------------------------------------------------------
Dekhne ka message        | Matlab                            | Fix
-------------------------|-----------------------------------|-----------------------------
invalid ownerid/secret   | name/ownerid/secret/version galat | panel se phir se copy karo
invalid username or key  | user/license exist nahi karta     | Users page me phle banao
subscription expired     | time khatam                        | Renew karo
user banned              | aapne/owner ne ban kiya hai        | Unban karo
hwid mismatch            | user doosre PC pe chala raha hai   | ResetHwid karo
server unreachable       | server URL galat / internet down   | api.Server check karo
